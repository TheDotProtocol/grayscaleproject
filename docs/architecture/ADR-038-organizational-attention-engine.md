# ADR-038: Organizational Attention Engine

**Status:** Accepted | **Date:** 2026-07-26

## Decision

Add `@grayscale/platform/attention` contracts and `AttentionEngineService`. CompanyContext.attention read-only. Athena discovery consumes attention in observe stage.

## Consequences

Attention measurable in Mission Control; AttentionForecast contract reserved for Phase C Digital Twin.
