# ADR-064: Organizational Foresight Engine

**Status:** Accepted | **Date:** 2026-07-26 | **Sprint:** 3 Phase D

## Decision

Adopt `ORGANIZATIONAL_FORESIGHT_ENGINE.md`. Implement `ForesightEngineService` with deterministic weak signal, trend, drift, and early warning detection. Executives consume; never generate foresight.

## Consequences

Forecast and scenario planning consume foresight. Mission Control widgets reserved.
