# ADR-075: Executive Collaboration Constitution

**Status:** Accepted  
**Date:** 2026-07-26  
**Sprint:** Sprint 4 Phase B

## Context

Organizational Runtime (Phase A) enables continuous operation. Executives can reason individually but lack a constitutional definition of **cooperation** — how they delegate, challenge, reach consensus, and escalate without becoming autonomous.

## Decision

1. Create `EXECUTIVE_COLLABORATION.md` as immutable constitutional document
2. Position after ORGANIZATIONAL_RUNTIME.md, before EXECUTIVE_COUNCIL_CONSTITUTION.md
3. Define 20 articles covering collaboration principles, boundaries, and governance
4. Require all executives inherit via CompanyContext

## Consequences

- Organization remains primary actor; executives are specialized contributors
- Collaboration certification gates enforce constitutional compliance
- No executive may communicate outside collaboration network

## Bedrock Extension Test

Bedrock executive framework defines lifecycle — not constitutional cooperation model. Additive constitutional layer.
