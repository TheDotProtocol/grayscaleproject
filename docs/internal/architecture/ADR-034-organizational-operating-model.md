# ADR-034: Organizational Operating Model

**Status:** Accepted  
**Date:** 2026-07-25  
**Sprint:** Constitutional Bridge — Sprint 2 → Sprint 3

## Context

Sprint 2 certified Athena and established executive-layer constitutions. The organization itself—how it reasons, remembers, learns, and evolves—required a constitutional definition independent of any executive or AI implementation.

## Decision

1. Create `docs/platform/ORGANIZATIONAL_OPERATING_MODEL.md` as immutable constitutional document
2. Position it in hierarchy after Founder Constitution, before Executive Philosophy
3. Introduce Organizational Digital Twin and Simulation as Sprint 3 concepts only—no implementation
4. Create `SPRINT3_FOUNDATION.md` as official Sprint 2 → Sprint 3 transition document
5. Update existing constitutional documents with references only—no principle rewrites

## Consequences

- All executives inherit organizational reasoning model via Bedrock context
- Sprint 3 scope is bounded by OOM concepts (Digital Twin, Simulation, Council, Forecast)
- No code, schema, or runtime changes in this ADR

## Non-negotiables

- Bedrock frozen
- Documentation only
- No executive owns organizational intelligence
