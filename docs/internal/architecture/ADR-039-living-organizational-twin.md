# ADR-039: Living Organizational Twin

**Status:** Accepted | **Date:** 2026-07-26

## Decision

Establish the Living Organizational Twin (LOT) as the single canonical, time-aware, versioned organizational operating model. One twin per company; past/present/future on same model.

## Consequences

Executives reason through twin; simulation and forecast attach to twin versions; Phase D multi-executive org consumes same port.
