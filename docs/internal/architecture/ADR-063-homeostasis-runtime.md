# ADR-063: Homeostasis Runtime

**Status:** Accepted | **Date:** 2026-07-26

## Decision

Expand Homeostasis Engine to v1.1.0 with `HomeostasisMetricDetail` on every score (reason, confidence, evidence, trend, history). Add metrics: adaptive capacity, recovery velocity, resilience index, organizational balance, failure cascade resistance, decision/attention saturation, executive/founder load, operational recovery, health momentum.

Deterministic assembly from Attention Engine. No recommendations.

## Consequences

Simulations capture homeostasis before/after. Mission Control homeostasis widgets consume expanded metrics.
