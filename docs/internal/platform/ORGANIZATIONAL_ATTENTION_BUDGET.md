## Article I — Attention Domains

The Attention Budget governs allocation across:

| Domain | Scope |
|--------|-------|
| Strategic attention | Long-horizon focus, goals, trade-offs |
| Operational attention | Execution, delivery, blocked work |
| Innovation attention | Experiments, R&D, new capabilities |
| Crisis attention | Immediate organizational threats |
| Emergency attention | Runtime-triggered urgent allocation |
| Opportunity attention | Time-sensitive positive options |
| Founder attention | Founder cognitive load (protected) |
| Executive attention | Per-executive consumption (not ownership) |

---

## Article II — Constitutional Principles

1. **Attention is finite** — total capacity is bounded and measurable
2. **Attention is measurable** — allocation, consumption, debt, recovery
3. **Attention is budgeted** — no unbounded cognitive load
4. **Attention is explainable** — every allocation records why, trigger, evidence
5. **Attention is versioned** — `ATTENTION_BUDGET_VERSION` on every snapshot
6. **Attention allocation is auditable** — append-only audit trail
7. **Attention allocation is organizational, never personal** — belongs to the org
8. **Executives consume attention** — they never create or own it
9. **Context switching has measurable cost** — recorded in consumption metrics
10. **Attention debt accumulates** — deferred items increase debt
11. **Attention starvation is measurable** — under-utilization detected
12. **Attention overload is measurable** — saturation states tracked
13. **Strategic focus must outweigh operational noise** — concentration ratio tracked
14. **Urgency is not automatically importance** — separate dimensions
15. **Attention budgets must adapt, never oscillate** — trend-based, not reactive swings

## Article III — Ownership Boundaries

| Layer | Role |
|-------|------|
| **Organization** | Owns attention as finite resource |
| **OrgOS Runtime** | Schedules attention refresh and allocation |
| **Attention Budget Module** | Measures, allocates, certifies — no reasoning |
| **Executives** | Consume allocated attention |
| **Mission Control** | Visualizes budget, debt, recovery |
