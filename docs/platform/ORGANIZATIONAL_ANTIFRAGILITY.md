# Organizational Antifragility

**Version:** 1.0.0 (Sprint 3 Phase D)  
**Status:** IMMUTABLE  
**ADR:** ADR-065

---

## Purpose

Measures how the organization **improves because of stress** — not merely survives it.

Antifragility complements Homeostasis (equilibrium) with growth-under-pressure metrics.

---

## Metrics

| Metric | Description |
|--------|-------------|
| Stress Gain | Net improvement from stress-recovery cycles |
| Adaptation Speed | Rate of domain adaptation |
| Failure Learning | Lessons from simulation/experiment exposure |
| Elasticity | Organizational balance elasticity |
| Recovery Acceleration | Velocity toward equilibrium |
| Innovation Pressure | Stress + experiment pressure |
| Experiment Quality | Simulation certification quality proxy |
| Resilience | Composite resilience index |
| Recovery Curve | Shape and duration of recovery |
| Organizational Flexibility | Adaptive capacity across domains |
| Institutional Growth | Health momentum as growth proxy |

Every metric: reason, confidence, evidence, trend, history.
