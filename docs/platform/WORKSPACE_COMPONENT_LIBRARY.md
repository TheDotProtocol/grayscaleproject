# Workspace Component Library

**RC1 Track A — `apps/web/src/components/workspace/`**

| Component | Purpose |
|-----------|---------|
| `Panel` | Glass-card section with title/icon |
| `StatCard` | Metric display |
| `LoadingState` / `ErrorState` / `EmptyState` | Status states |
| `KeyValueGrid` | Object field display |
| `DataList` / `TimelineList` | List rendering |
| `ScoreBadge` | Percentage scores |
| `GenericDataView` | API-backed adaptive renderer |
| `CommandPalette` | Universal navigation (⌘K) |
| `WorkspacePageShell` | Standard page layout |

Mission Control: `WidgetRenderer` + `renderExtendedWidget` for Sprint 3/4 widgets.

---

Design tokens: `globals.css` — dark theme, glass-card, gradient accents.
