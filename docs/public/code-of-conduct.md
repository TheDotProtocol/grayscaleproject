# Code of Conduct

## Our Pledge

We pledge to make participation in the Grayscale community a harassment-free experience for everyone, regardless of background, identity, or experience level.

---

## Expected Behavior

- Use welcoming and inclusive language
- Respect differing viewpoints and experiences
- Accept constructive criticism gracefully
- Focus on what is best for the community and platform
- Show empathy toward other community members

---

## Unacceptable Behavior

- Harassment, trolling, or personal attacks
- Publishing others' private information without permission
- Sharing internal constitutional or certification documentation publicly
- Attempting to extract or redistribute proprietary executive prompts
- Other conduct inappropriate in a professional setting

---

## Enforcement

Community leaders may remove, edit, or reject contributions and communications that violate this Code of Conduct.

Report violations to [info@projectgrayscale.com](mailto:info@projectgrayscale.com).

---

## Scope

This Code of Conduct applies in community spaces, GitHub interactions, events, and any context representing Project Grayscale.
