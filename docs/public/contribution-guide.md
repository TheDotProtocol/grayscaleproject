# Contributing

Thank you for your interest in contributing to Project Grayscale.

---

## What We Accept

| Area | Examples |
|------|----------|
| **Plugins & Connectors** | GitHub, CRM, industry data connectors |
| **Documentation** | Fixes and improvements to `docs/public/` |
| **SDK Examples** | Reference implementations using `@grayscale/plugin-sdk` |
| **Bug Reports** | Reproducible issues with clear steps |

| Area | Contact |

## Pull Request Guidelines

1. **Scope** — One concern per PR
2. **Documentation** — Update `docs/public/` for user-facing changes
3. **No secrets** — Never commit `.env`, credentials, or prompt packs
4. **No internal docs** — Do not add constitutional or certification material to `docs/public/`
5. **Tests** — Include tests for functional changes (when applicable)
