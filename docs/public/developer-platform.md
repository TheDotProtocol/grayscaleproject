# Build on Grayscale

Grayscale OS is an **operating system for organizations**. Developers build **on top** of the platform — they do not recreate it.

---

## What You Build

| Extension Type | Description |
|----------------|-------------|
| **Plugins** | Connectors, sync jobs, capability extensions |
| **Executives** | Domain-specific advisory modules (certification required) |
| **Marketplace Modules** | Certified third-party capabilities (roadmap) |
| **Connectors** | GitHub, CRM, billing, industry data sources |
| **Industry Packs** | Vertical templates — legal, healthcare, logistics |
| **Integrations** | Webhooks, API clients, workflow bridges |
| **Dashboards** | Custom Mission Control widgets (approved contracts) |
| **Widgets** | Read-only organizational data visualizations |
| **Automation Policies** | Governance-approved workflow rules |

---

## What You Do Not Build

Grayscale protects its commercial core. Developers must **not** attempt to:

- Replicate Bedrock or the event-sourced runtime
- Rebuild CompanyContext assembly
- Bypass Policy Engine or Governance Kernel
- Fork the full OOS as a competing product
- Extract or redistribute executive prompt packs

---

## Extension Points

1. **Plugin SDK** — `@grayscale/plugin-sdk` connector model
2. **HTTP APIs** — Mission Control, Intelligence, Integration, Operations
3. **Event subscriptions** — React to organizational events (sandbox-gated)
4. **Webhook receivers** — Inbound signals with policy evaluation

---

## Philosophy

> Build **with** Grayscale. Extend organizational judgment. Never replace constitutional governance.

Stripe provides payments infrastructure — you build businesses on it.  
Grayscale provides organizational infrastructure — you build capabilities on it.
