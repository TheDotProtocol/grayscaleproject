# Executives

Executive Intelligence augments organizational judgment — it does not replace founder authority.

---

## Overview

Grayscale supports multiple **executives** — specialized advisory modules that reason over CompanyContext, produce explainable recommendations, and participate in structured deliberation.

Executives **advise, debate, and challenge**. They do not execute without governance approval.

---

## Key Concepts

| Concept | Description |
|---------|-------------|
| Recommendation Pipeline | Evidence-based suggestions with confidence scoring |
| Executive Compliance Suite | Certification gates before activation |
| CompanyContext | Single read-only state for all executive reasoning |
| Founder Authority | Final decisions remain with the founder |

---

## Activation

Executives are **certification-gated** and disabled by default:

```
EXECUTIVES_ENABLED=false
```

Activation requires certification completion and founder approval.

---

## Build Executive Extensions

Third-party executives are developed through the [Partner Program](/docs/licensing/partner). See [Athena](/docs/athena) for the reference executive model.
