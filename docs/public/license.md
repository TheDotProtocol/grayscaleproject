# License

**Grayscale OS v1.0 — Licensing Overview**

---

## Current Status

Project Grayscale does not yet publish a final open-source license for the full platform. Licensing tiers are documented as placeholders while legal review completes.

**Do not assume MIT, Apache, or other permissive licensing for the core platform.**

## Developer Extensions

Plugin SDK and connector packages are intended for a **permissive license** (Apache-2.0 target) when extracted to `grayscale-sdk`. The core platform remains commercial.

See strategy overview in repository governance documentation.
