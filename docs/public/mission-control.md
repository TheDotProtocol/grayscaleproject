# Mission Control

Mission Control is the founder's operational command center — health, readiness, timeline, and widgets in one surface.

---

## Purpose

Founders, COOs, and boards need **one place** for organizational truth. Mission Control aggregates live data from across Grayscale without noise or duplicate dashboards.

---

## Key Features

- **Platform Health** — Bedrock subsystem status
- **Company Readiness** — Organizational preparedness (distinct from platform health)
- **Live Widgets** — Configurable operational displays
- **Unified Timeline** — Event-sourced organizational history
- **Search** — Cross-organizational discovery
- **Command Palette** — Quick navigation and actions

---

## Access

Founder workspace: `/dashboard/mission-control`

Requires authenticated founder session.

---

## For Developers

Build **read-only widgets** that consume approved Mission Control API contracts. Widgets display organizational state — they do not bypass governance.
