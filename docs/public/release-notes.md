# Release Notes

## Grayscale OS v1.0 — Codename Bedrock

**Release Date:** July 26, 2026  
**Status:** Commercial Launch

---

### Highlights

Grayscale OS v1.0 is the first commercial release of Project Grayscale — an **Organizational Operating System** for founders, executives, and boards.

This release declares Foundation (Bedrock) and Sprints 2–4 complete, architecture frozen, and Grayscale ready for commercial launch.

---

### Platform Capabilities

- **Bedrock** — Event-sourced platform, memory, graph, intelligence
- **Mission Control** — Founder command surface with live widgets
- **Executive Intelligence Layer** — Multi-executive framework (certification-gated)
- **Organizational Nervous System** — Digital twin, simulation, foresight
- **OrgOS** — Organizational runtime, heartbeat, scheduling
- **Executive Council** — Structured deliberation pipeline
- **Policy Engine + Governance Kernel** — Constitutional permission before execution
- **CompanyContext** — Unified read-only organizational state
