# Digital Twin

A living model of your organization assembled from unified organizational state.

---

## Overview

The Digital Twin represents organizational health, alignment, and dynamics — derived from CompanyContext, not fabricated confidence scores.

---

## Key Metrics

| Metric | Description |
|--------|-------------|
| Twin Health | Overall model integrity |
| Alignment | Strategy ↔ execution coherence |
| Signal Correlation | Cross-source signal agreement |
| Homeostasis | Organizational balance indicators |

---

## Use Cases

- Founder briefing on organizational state
- Mission Control widget displays
- Simulation input baseline
- Executive reasoning context
